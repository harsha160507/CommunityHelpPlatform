Community Help Platform

About the Project

The Community Help Platform is a web-based application developed to connect NGOs with people who want to help their communities. It provides a common platform where NGOs can organize events and volunteers can find opportunities to participate in social activities.

Features

- User Registration and Login: NGOs and volunteers can create accounts and log in.
- NGO Management: Admin can approve or reject NGO registrations.
- Event Management: Approved NGOs can create events with details such as date, time, and location.
- Event Approval: Admin can approve or reject events created by NGOs.
- Volunteer Participation: Volunteers can view approved events and register to participate.
- Admin Dashboard: Admin can manage NGOs, volunteers, and events.

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

User Roles

1. Admin: Manages NGO registrations, volunteers, and events.
2. NGO: Registers on the platform and creates events after approval.
3. Volunteer: Explores available events and participates in community activities.

Objective

The main objective of this project is to encourage community service by making it easier for NGOs to connect with volunteers and organize social activities.

Project Structure

- "Frontend/" – Contains HTML, CSS, and JavaScript files.
- "Backend/" – Contains the Node.js server, API routes, database connection, and configuration files.

How to Run the Project

1. Install Node.js and MySQL.
2. Configure the database credentials in the backend ".env" file.
3. Open the Backend folder in the terminal.
4. Run "npm install".
5. Run "npm start".
6. Open the frontend "index.html" file in a browser.

Note: Make sure the database is configured and the backend server is running before testing the website.

Conclusion

The Community Help Platform aims to make community service more accessible by bringing NGOs and volunteers together through a simple and user-friendly website.
