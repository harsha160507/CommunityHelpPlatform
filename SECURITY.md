# Security policy

Do not include credentials, tokens or personal data in public reports. Contact the repository owner privately through their GitHub profile before disclosing an exploitable issue. No private reporting address is asserted here.

Supported code is the current main branch after reviewed fixes are merged. Operators are responsible for installing dependency updates, rotating secrets and configuring HTTPS, SMTP, database access and backups.

See docs/SECURITY-RESPONSE.md for the previously committed .env incident and required owner actions. Never infer that removal from Git has rotated a live secret.
